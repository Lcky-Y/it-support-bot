# 网络故障知识库

## SSL 证书错误

### 关键词
SSL SSLError CERTIFICATE_VERIFY_FAILED 证书 错误 https verify 证书验证

### 症状
- SSLError: CERTIFICATE_VERIFY_FAILED
- 访问 https 报证书错误

### 常见原因
- 代理/防火墙替换证书
- 系统时间错误
- 证书过期或不受信任

### 检查命令
- curl -v <url>

### 解决思路
- 校正系统时间
- 配置受信任的 CA 证书
- 检查代理是否拦截

## 请求超时

### 关键词
timed out 超时 timeout 请求 连接 慢 无响应

### 症状
- 请求长时间无响应或超时

### 常见原因
- 网络不稳定
- 代理/防火墙限制

### 检查命令
- curl -v <url>
- ping <主机>

### 解决思路
- 检查代理设置
- 增大客户端 timeout
- 更换网络重试

## 代理设置

### 关键词
proxy 代理 vpn 7890 clash 梯子 http.proxy 翻墙

### 症状
- 需要配置或排查代理

### 常见原因
- 代理未开启或未配置到工具
- 代理与工具冲突

### 检查命令
- 检查系统代理或代理工具

### 解决思路
- pip：pip install <包> --proxy http://127.0.0.1:7890
- git：git config --global http.proxy http://127.0.0.1:7890

## DNS 解析失败

### 关键词

### 症状
- getaddrinfo failed
- 域名无法解析

### 常见原因
- DNS 服务器不可用
- 域名拼写错误
- hosts 文件被改

### 检查命令

### 解决思路
- 更换 DNS（223.5.5.5 / 8.8.8.8）
- 检查 hosts 文件
- 核对域名拼写

## 内网 / 外网区分

### 关键词
内网 外网 局域网 公网 IP 访问 无法访问 网络环境

### 症状
- 内网可访问、外网不可，或相反

### 常见原因
- 网络环境限制
- 端口未映射

### 检查命令
- ipconfig / ip addr

### 解决思路
- 确认所在网络环境
- 内网服务需端口映射才能外网访问
- 检查防火墙/安全组
